# Mobile App Development

This repository contains the CampusCompanion iOS project.

## CampusCompanion

CampusCompanion is a storyboard-based UIKit app for campus events and announcements. It includes:

- UserDefaults persistence for the student's name, notification preference, and role.
- A Reset Preferences control on the welcome screen.
- Core Data persistence for campus announcements.
- REST API refresh using URLSession and Codable JSON parsing.
- One-time announcement seeding, adding, sorting, and swipe-to-delete support.
- Server synchronization with Location and Priority fields.
- A reusable announcement list and detail view.

Open `CampusCompanion/CampusCompanion.xcodeproj` in Xcode to inspect or run the project.
